# practicas-github

Repositorio de práctica para aprender Git y GitHub paso a paso.

## Objetivo

Aprender a utilizar GitHub con soltura mediante ejercicios sencillos y controlados.

## Prácticas realizadas

### 1. Crear un repositorio
Se creó este repositorio con un archivo `README.md` inicial.

### 2. Crear una rama
Se creó la rama `prueba-readme` a partir de `main`.

La rama permite realizar cambios sin modificar directamente la versión principal del proyecto.

### 3. Modificar el README en una rama
Se añadió una sección nueva al README dentro de `prueba-readme`.

Después se comprobó que:
- el cambio aparece en `prueba-readme`;
- el cambio no aparece todavía en `main`.

## Próximo paso

Crear un Pull Request para revisar los cambios de `prueba-readme` antes de incorporarlos a `main`.
